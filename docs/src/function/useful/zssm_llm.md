# 这是什么？

:::tip
目前仅在云梦都 QQ 群中使用；QQ 官方机器人、QQ 频道、KOOK 和私聊暂不支持。
:::

## 概述

碰到不认识的名词，或一张看不懂的图？带来问问幽幽子吧～

## 解释文字

- 指令：`/这是什么 [内容]`
- 别名：`zssm [内容]`

```text
/这是什么 弹幕游戏
```

不想重新复制内容？引用一条消息，再发送 `zssm` 就好；引用文字消息时，也可以在指令后补充自己最想了解的部分。

## 解释图片或图文

想问图片里的内容，就把指令和图片放在**同一条消息**里，或者引用已有图片消息后发送指令。

- 可以只解释图片，也可以同时带上文字，结合图文进行解释。
- 一次最多 **两张图片**，引用消息和当前消息中的图片合计计算。
- 记得把图片和指令一起送过来，或通过引用提供；先发空指令、再单独发图，幽幽子不会自动等下一张图片哦。

## 消息中的链接

输入或引用的消息含有网页链接时，会尝试读取并解释**第一个链接**的页面内容。能否读取取决于页面是否可以正常访问。

## 使用提示

- 没有输入或引用内容时，会提示补充内容。
- 图片读不到、或解释暂时失败时，稍后再来问问就好。
- AI 解释可能有遗漏或错误，不确定的内容请再核实。
- 没有回应时，先确认所在群是否开放了这个功能；它不会自动解释普通聊天。
