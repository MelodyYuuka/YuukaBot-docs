# 化学工具

:::warning
由于腾讯的要求，本功能在 `QQ官方` 平台上暂不可用
:::

## 概述

本功能实现了 化学相关 功能

## 指令

### 配平

- 指令： `配平[化学方程式]`

- 别名： `/配平`

- 参数：

  - `化学方程式`： 要配的方程式

- 详情：

  配平化学方程式，支持常见方程式、离子方程式和电子表示。

  手机输入法常见的全角符号，以及 `H₂O` 这类数字下标，也可以直接使用。

:::tip
支持离子/电子，表示为{xxx}

如：

- Cr2O7{-2} 表示 $Cr_{2}O_{7}^{-2}$
- {-} 表示 e
- Cr{+3} 表示 $Cr^{+3}$

:::

## 输入示例

```text
/配平 H2 + O2 = H2O
```

配平后各物质的系数为 `2 : 1 : 2`，对应 `2H2 + O2 = 2H2O`。离子电荷请使用上面的花括号格式。
