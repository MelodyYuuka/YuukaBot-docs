# 节假日

:::tip
该功能已注册 **推送服务**，详见 [服务管理](../admin/task_manager.md)
:::

## 概述

还有几天放假？明天要不要补班？让幽幽子帮你翻翻日历，别到了假期最后一天才想起来调闹钟呀~

这里查询的是中国大陆公布的节假日与调休安排，也可以订阅群内提醒。

## 最近假期

- 指令：`/节假日`
- 别名：`/最近节假日`、`/下个节假日`、`/放假倒计时`

查看最近假期、放假倒计时和相关补班日。正在放假时，会告诉你当前假期还剩几天；下一次假期已公布的话，也会一起列出来。

## 明天上班吗

- 指令：`/节假日 [日期]`

| 指令 | 查询内容 |
| --- | --- |
| `/节假日 今天` | 今天的作息 |
| `/节假日 明天` | 明天放假还是上班 |
| `/节假日 后天` | 后天的作息 |
| `/节假日 2026-10-01` | 指定日期的安排 |

:::tip
现在查作息统一用 `/节假日`，旧的 `/上班吗`、`/明天上班吗` 不再使用啦。
:::

## 全年放假安排

- 指令：`/放假安排 (年份)`
- 也可以用：`/节假日 [年份]`

不填年份时查看今年。例如：

```text
/放假安排
/放假安排 2026
/节假日 2026
```

会列出全年已经公布的假期和调休上班日，做出行计划时可以先瞄一眼。

## 每晚提醒

想让群里每天提醒一下，可以使用：

| 指令 | 效果 |
| --- | --- |
| `开启任务 节假日提醒` | 订阅每日提醒 |
| `关闭任务 节假日提醒` | 取消订阅 |

开启后，每天**北京时间 20:00** 开始推送假期和明日作息信息，补班前也会提醒。

任务开关的权限与平台限制见 [定时任务管理](../admin/task_manager.md)。只想偶尔查一次的话，不必开启提醒，直接发查询指令就好。

## 小提醒

- 普通周末按双休计算，实际作息还是要以学校或单位安排为准哦。
- 支持查询 2007 年起至次年年底的日期，以已经公布的数据为准；没公布的假期不会提前猜一个出来。
- 跨年安排还不完整时，只展示能确认的部分。
