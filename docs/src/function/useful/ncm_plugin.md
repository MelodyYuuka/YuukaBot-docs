# 网易云音乐功能

## 概述

今天想听哪一首？可以先搜搜歌、翻页挑选，也可以直接按歌名或歌曲 ID 点歌，让幽幽子帮你找来～想用其他平台，请看 [点歌相关](./music.md)。

## 指令

### 点歌

- 指令： `点歌 [关键词](*序号)`

- 别名： `/点歌`、`163点歌`、`网易云点歌`

- 参数：

  - `关键词`： 歌名、歌手或专辑名等搜索关键词
  - `*序号`： 可选参数，指定搜索结果中的第几首歌，不填时选择第一首

- 详情：

  网易云音乐点歌

- 使用示例：

  ```text
  /点歌 童祭
  /点歌 少女秘封倶楽部*2
  ```

### 搜歌与翻页

- 指令： `搜歌 [关键词](*页码)`

- 别名： `/搜歌`、`163搜歌`、`网易云搜歌`

- 参数：

  - `关键词`： 歌名、歌手或专辑名等搜索关键词
  - `*页码`： 可选参数，填写正整数，不填时查看第一页

- 详情：

  搜索网易云音乐曲子

- 使用示例：

  ```text
  /搜歌 童祭
  /搜歌 童祭*2
  ```

:::tip
小提醒：点歌后的 `*序号` 是挑第几首歌，搜歌后的 `*页码` 是翻到第几页，别弄混啦。

已经在列表里挑好了？用那一项的歌曲 ID 点歌，就不用再确认搜索排序了。
:::

### 按歌曲 ID 点歌

- 指令： `点歌 ID:歌曲ID`

- 别名： `/点歌 ID:歌曲ID`

- 参数：

  - `歌曲ID`： 网易云歌曲的正整数 ID；`ID:` 不区分大小写

- 详情：

  直接按歌曲 ID 点歌，也可以使用搜索结果给出的对应指令。

## 使用提示

- 关键词及附带参数合计不超过 100 字，不要加入换行或控制字符。
- 没搜到想听的歌，可以换个关键词试试；翻到没有更多歌曲的页数时，回前一页继续挑就好。
