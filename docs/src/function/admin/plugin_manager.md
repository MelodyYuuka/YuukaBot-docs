# 功能管理

:::info
本页介绍 QQ 第三方野生 Bot 的功能与名单模板管理。设置本群名单模板需要群主或管理员权限。

QQ 官方机器人请使用 [功能管理（for QQ官方）](./plugin_manager_bot.md) 中的管理菜单。
:::

## 概述

YuukaBot-v6 提供了 **功能管理** 这一模块来方便各群更好的使用 Bot 与管理群员使用 Bot 服务。

## 指令

### 查看所有功能

- 指令： `查看所有功能`

- 详情：

  查看所有功能

### 查看功能帮助

- 指令： `查看功能帮助[功能名]`

- 参数：
  - `功能名`： 在 [**查看所有功能**](/function/admin/plugin_manager.md#查看所有功能) 中获取到的功能名

- 详情：

  查看该功能收录的指令帮助，不会修改首选 Bot 或功能开关。

:::warning
本文档有更为详尽的功能帮助，上述指令可用于 群管开关功能时确认功能名
:::

### 查看所有名单模板

- 指令： `查看所有名单模板`

- 详情：

  查看所有名单模板

### 查看名单模板

- 指令： `查看名单模板[模板名]`

- 参数：
  - `模板名`： 功能名单模板名

- 详情：

  查看该名单模板

### 设置本群名单模板 <Badge type="tip" text="群管或群主" vertical="top" />

- 指令： `设置本群名单模板[模板名]`

- 参数：
  - `模板名`： 功能名单模板名

- 详情：

  让本群使用该名单模板。按提示输入 `确认` 后，会替换本群的名单模式和功能名单，原有的自定义功能名单不会保留。
