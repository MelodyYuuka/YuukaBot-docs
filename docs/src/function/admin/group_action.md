# 群管理操作

:::info
支持 QQ 第三方 Bot 和 QQ 官方机器人，由群主或管理员操作，机器人自身也需要相应管理权限。

使用 QQ 官方机器人时，还需要先开启**全量消息**，并将机器人设为管理员。可以发送 `/免艾特申请` 查看全量消息的开启步骤。
:::

## 概述

让需要冷静的小伙伴休息一会儿，也可以提前解除禁言。一次支持操作多名成员。

## QQ 官方机器人使用提醒

- 请在 QQ 的 `@` 弹出列表里**选中成员**，只打出 `@昵称` 或填写 QQ 号是不行的。
- 如果输入 `@` 后没有弹出列表，可以先在前面加一个空格。
- 不能禁言群主、管理员或机器人。

## 指令

### /禁言 <Badge type="tip" text="群管或群主" vertical="top" />

- 指令： `/禁言[用户] [时间]`
- 别名： `.mute`、`/mute`

- 参数：

  - `用户`： 支持[**艾特**](/about/glossary.md#%E8%89%BE%E7%89%B9)多名用户；QQ 第三方 Bot 还可以填写 QQ 号，多个 QQ 号用空格分隔
  - `时间`： 形如 `1d2h3m4s`，依次表示天、小时、分钟、秒，可以省略不需要的单位；QQ 官方机器人支持大于 0、最多 30 天的时长

- 详情：

  禁言用户

- 使用示例：

  - `/禁言@xxx@yyy 1d`: 禁言 `xxx` 和 `yyy` 一天
  - 仅 QQ 第三方 Bot：`/禁言12345 67890 1d2h3m4s`: 禁言 QQ号 为 `12345` 和 `67890` 的两位 一天两小时三分钟四秒
  - `/禁言@abc 1m`: 禁言 `abc` 一分钟

:::tip
对于禁言秒数：QQ 所显示禁言时间仅会精确到分钟，但实际上是正确的时间
:::

### /解禁 <Badge type="tip" text="群管或群主" vertical="top" />

- 指令： `/解禁[用户]`
- 别名： `.unmute`、`/unmute`

- 参数：

  - `用户`： 支持[**艾特**](/about/glossary.md#%E8%89%BE%E7%89%B9)多名用户；QQ 第三方 Bot 还可以填写 QQ 号，多个 QQ 号用空格分隔

- 详情：

  解禁用户

- 使用示例：

  - `/解禁@xxx@yyy`: 解禁 `xxx` 和 `yyy`
  - 仅 QQ 第三方 Bot：`/解禁12345 67890`: 解禁 QQ号 为 `12345` 和 `67890` 的两位
