# 东方问答

## 原曲认知

### 开始原曲认知

- 指令： `*原曲认知(范围名)`

- 别名： `/原曲认知`

- 参数：

  - `范围名`：可选参数，可用 [**查看原曲范围列表**](/function/touhou/touhou_quiz.md#查看原曲范围列表) 获取

### 设置原曲范围 <Badge type="tip" text="群管或群主" vertical="top" />

- 指令： `*设置原曲范围[范围名]`

- 参数：

  - `范围名`：可用 [**查看原曲范围列表**](/function/touhou/touhou_quiz.md#查看原曲范围列表) 获取

- 详情：

    设置本群原曲范围

### 查看原曲范围列表

- 指令： `*查看原曲范围列表`

- 详情：

    查看所有原曲范围

### 回答原曲认知

- 指令： `*这是[答案]`

- 参数：

  - `答案`：答案选项

## 困难原曲认知

困难模式不会给出选项，需要根据音频片段直接写出原曲名。

### 开始困难原曲认知

- 指令： `*困难原曲认知(范围名)`

- 别名： `/困难原曲认知`

- 参数：

  - `范围名`：可选参数，可用 [**查看原曲范围列表**](/function/touhou/touhou_quiz.md#查看原曲范围列表) 获取

### 回答困难原曲认知

- 指令： `*这是原曲[原曲名]`

- 别名： `/这是原曲`

- 参数：

  - `原曲名`：玩家猜测的原曲名

- 详情：

  支持模糊匹配，也可以使用当前原曲的其他名称或长标题中的一部分。

### 放弃困难原曲认知

- 指令： `*放弃困难原曲认知`

- 别名： `/放弃困难原曲认知`

- 详情：

  结束当前困难原曲认知并揭晓答案。
