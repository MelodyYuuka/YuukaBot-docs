# 东方角色百科

## 概述

东方角色百科是一个查询东方 Project 角色资料的功能，资料来自 THBWiki。

支持查看角色的概览、简介与完整资料。角色名支持正式名称、日文名、英文名与别名，可以进行模糊搜索。

概览包含角色的日文名、英文名、别名、分类、初次登场作品、种族与官方登场次数等信息；完整资料还包含简介、生活经历、能力、外貌与人际关系。

## 指令

### 查角色资料

- 指令： `/角色资料 [角色名]`

- 别名： `/东方角色百科`, `/查东方角色`

- 参数：

  - `角色名`： 角色名，支持正式名称、日文名、英文名与别名，支持模糊搜索

- 详情：

  查看东方角色概览，附带角色立绘，可以直接跳转查看简介或完整资料

### 随机角色

- 指令： `/角色资料 随机`

- 详情：

  随机查看一位东方角色的概览

### 查看角色简介

- 指令： `/角色资料 [角色名] 简介`

- 详情：

  单独查看指定东方角色的简介

### 查看角色完整资料

- 指令： `/角色资料 [角色名] 详情`

- 详情：

  查看指定东方角色的完整资料，包括简介、生活经历、能力、外貌与人际关系

### 角色资料帮助

- 指令： `/角色资料帮助`

- 详情：

  查看东方角色百科的使用说明
