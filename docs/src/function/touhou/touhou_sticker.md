# 东方表情包

## 概述

东方表情包功能为用户提供了东方 Project 相关的表情包服务。
用户可以通过指令随机获取一张东方表情包，或者根据角色名称搜索特定角色的表情包。
支持模糊搜索，方便用户快速找到自己喜欢的角色表情包。

角色名也支持常用别名和假名简称，例如 `/搜东方表情包 幽幽子`。更多示例见 [角色名与别名](./#角色名与别名)；该角色没有已收录的表情包时会给出提示。

## 指令

### 随机东方表情包

- 指令：`/随机东方表情包 (角色名)`

- 参数：

  - `角色名`：角色名称，可选，不填随机角色，支持模糊搜索，支持简体中文、日文、英文和常用别名

- 详情：

  随机一张东方表情包~

### 搜东方表情包

- 指令：`/搜东方表情包 [角色名]`

- 参数：

  - `角色名`：角色名称，支持模糊搜索，支持简体中文、日文、英文和常用别名

- 详情：

  搜索东方表情包
