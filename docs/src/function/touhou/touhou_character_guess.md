# 猜东方角色

## 概述

猜东方角色是一个猜测东方 Project 角色的游戏，玩家需要在 8 次猜测内猜出答案。开局后 bot 会随机选定一位东方角色，玩家提交猜测后，bot 按 7 个角色特征标签比对猜测与答案的差异，并生成反馈表格图。

每次猜测后，bot 会按标签给出命中反馈：

- 绿色 = 命中
- 黄色 = 接近（数值差 ≤ 5，或同大类但小类不同）
- 灰色 = 不符

数值标签（初登场年份）会给出 `↑` / `↓` 的高低提示，帮助缩小范围。7 个标签为：初登场年份、初登场作品、发色、是敌人吗？（整数非对战新作）、是自机吗？、所属地点、种族。

## 指令

### 猜东方角色

- 指令： `/猜东方角色`

- 详情：

  开始一局猜东方角色游戏

### 我猜东方角色是

- 指令： `/我猜东方角色是 [角色名]`

- 参数：

  - `角色名`： 猜测的东方角色名

- 详情：

  猜测角色，获取特征标签反馈

### 结束猜东方角色

- 指令： `/结束猜东方角色`

- 详情：

  结束当前游戏并揭露答案

### 使用猜东方角色帮助

- 指令： `/使用猜东方角色帮助`

- 详情：

  获取猜东方角色游戏的玩法说明
