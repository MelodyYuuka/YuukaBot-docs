# 猜符卡

## 概述

只露出一小角的弹幕，你还能认出是哪张符卡吗？

从局部截图猜符卡名称。猜错也别急，画面会逐渐展开，还会掉落作品、难度和角色线索。

## 开始游戏

- 指令：`/猜符卡 (作品或分类)`

不加参数时从全部题库随机出题，也可以限定作品或分类：

| 指令示例 | 出题范围 |
| --- | --- |
| `/猜符卡` | 全部题库 |
| `/猜符卡 弹幕作` | 新作整数作与小数点弹幕作，也可写 `/猜符卡 弹幕` |
| `/猜符卡 黄昏作` | 黄昏合作作品，包含格斗作品和《东方刚欲异闻》，也可写 `/猜符卡 黄昏` |
| `/猜符卡 东方红魔乡` | 只猜指定作品，也可使用作品简称，如 `/猜符卡 红魔乡` |

原有的作品与分类名称仍可使用。选择「弹幕作」或「黄昏作」后，开局消息会注明本局范围。

支持按钮的平台还可以从玩法帮助或结算消息中点击「弹幕作」「黄昏作」快速开局；不支持按钮时直接发送对应指令即可。

同一个群聊或私聊同时只能进行一局。群聊里大家一起猜，共用 **12 次机会**。

## 提交猜测

- 指令：`/我猜符卡是 [符卡名]`

例如：

```text
/我猜符卡是 恋符「Master Spark」
```

可以使用日文名、中文名、符卡名主体或括号中的译名，常见的难度标记也可以省略。少量错字会尝试模糊匹配，不必为记不清标点发愁。

猜错后，截图范围会逐渐扩大，直到展示完整的可见区域；题图中的名称会隐藏，避免提前揭晓答案。画面已经展开后，就不会反复发送同一张题图了。

| 猜错次数 | 新线索 |
| --- | --- |
| 第 3 次 | 所属作品 |
| 第 6 次 | 关卡、难度 |
| 第 9 次 | 使用这张符卡的角色 |

:::tip
重复提交同一个答案也会消耗机会，换个思路再试试吧。空输入或过长的输入会被拦下，不扣次数。
:::

## 结束游戏

- 指令：`/结束猜符卡`
- 别名：`/放弃猜符卡`

想看答案了就用这个。猜中、机会用完或主动结束后，都会揭晓符卡名称和完整原图。
