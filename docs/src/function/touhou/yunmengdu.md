# 云梦都相关

:::tip
本功能主要是支持幽幽子官方群 [云梦都](https://qm.qq.com/q/RHZqFoSmac) 的一些功能，包括 `Minecraft 服务器` 等
:::

## 指令

### QQ 绑定 Minecraft 账号

:::tip
`/mc绑定` 可以在任意云梦都 QQ 群中使用，不再限定单个 Minecraft 服务器群。
:::

- 指令：`/mc绑定 [验证码]`

- 用法：

  先连接 Minecraft 服务器，在游戏登录提示中获取 8 位数字验证码，然后在 QQ 群发送该指令。验证码有效期为 30 分钟，允许以 `0` 开头。

- 查询绑定：`/查询绑定` 或 `/checkbind`

  查看当前 QQ 已绑定的游戏账号，也可以艾特其他用户查询。

- 换绑：

  先在游戏内执行 `/qq换绑`（别名 `/qqrebind`）获取新验证码，再由新的 QQ 账号发送 `/mc绑定` 完成换绑。

绑定成功后请重新连接 Minecraft 服务器。

### 查看在线人数

- 指令： `/online`

- 详情：

  查看云梦都 MC 服务器在线人数

### 向服务器发送消息 <Badge type="tip" text="仅云梦都" vertical="top" />

- 指令： `/msgs[消息]`

- 参数：

  - `消息`： 要发送的消息

- 详情：

  向服务器内发送消息

### 设置皮肤 <Badge type="tip" text="仅云梦都" vertical="top" />

- 指令： `/设置皮肤 [游戏名]`

- 别名： `/setskin`

- 参数：

  - `游戏名`： 要设置的游戏名，可选，默认随机一个已绑定的游戏名

- 详情：

  设置服务器内皮肤，皮肤图片可以紧随其后或者在下一条消息中发送

### 玩家信息 <Badge type="tip" text="仅云梦都" vertical="top" />

- 指令： `/玩家信息 [游戏名]`

- 别名： `/playerinfo`

- 参数：

  - `游戏名`： 要设置的游戏名，可选，默认随机一个已绑定的游戏名

- 详情：

  设置服务器内皮肤，皮肤图片可以紧随其后或者在下一条消息中发送
