## 角色名与别名

填写东方角色名时，可以使用正式名称、常用别名，以及部分日文写法或假名简称。以下写法适用于 [东方角色百科](./touhou_wiki.md)、[猜东方角色](./touhou_character_guess.md)、[随机东方图](./random_touhou.md) 和 [东方表情包](./touhou_sticker.md) 等功能：

| 角色 | 可用写法示例 |
| --- | --- |
| 博丽灵梦 | `灵梦`、`红白`、`れいむ` |
| 雾雨魔理沙 | `魔理沙`、`黑白`、`まりさ` |
| 西行寺幽幽子 | `幽幽子`、`ゆゆこ` |
| 古明地恋 | `恋恋`、`こいし` |

例如，发送 `/角色资料 恋恋`、`/随机东方图 ゆゆこ` 或 `/搜东方表情包 幽幽子`。

如果没有找到或结果不符合预期，可以改用正式角色名。各功能收录的角色范围不同，能够识别别名不代表一定有对应的题目、资料或图片。
