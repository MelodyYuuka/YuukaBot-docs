## 平台与使用限制

QQ 群、QQ 频道和 KOOK 的能力不同，具体功能页中的限制优先于分类介绍。例如图片编辑、化学工具在 QQ 官方平台暂不可用；管理功能还可能要求群主或管理员权限。完整对照见[各平台局限性](../FAQ/#各平台局限性)。

## 指令参数怎么看？

:::tip
除特别说明外，括号内代表这是一个参数，任意指令参数**均不需要**输入括号

在参数中：

 **`()`** 代表 可选参数

 **`[]`** 代表 必选参数

 用 **`|`** 隔开的表示 可选择项，择其一即可
:::

::: warning
目前 **YuukaBot-v6** 仍在快速迭代，某些指令仍然可能会改变，包括指令名与参数要求、分类等。
:::

:::info
目前部分功能已支持私聊使用
:::
