# 宝可梦猜剪影

## 概述

只看轮廓，你认得出是哪只宝可梦吗？猜中以后，幽幽子就会揭晓完整图片～可以和群友一起猜，也可以私聊单人游玩，**不限制猜测次数和时间**，慢慢认就好。

喜欢看轮廓，还是喜欢分析属性？这和 [猜宝可梦](./pokemonle.md) 是两种独立玩法：这里看剪影，那边根据属性表推理，可以换着玩。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/宝可梦猜剪影` | 从全部题库中开局 |
| `/宝可梦猜剪影 (世代)` | 从指定世代中选择答案 |
| `/我猜宝可梦剪影是 [名称]` | 提交猜测 |
| `/宝可梦猜剪影提示` | 获取下一条线索 |
| `/结束宝可梦猜剪影` | 结束本局并揭晓答案 |
| `/宝可梦猜剪影帮助` | 查看玩法说明 |
| `/宝可梦猜剪影战绩` | 查看个人战绩 |

## 选择世代

不填范围，或填写「全部」，使用全部题库；可以填写 1～9，也可以写「第一世代」至「第九世代」。

```text
/宝可梦猜剪影
/宝可梦猜剪影 1
/宝可梦猜剪影 第九世代
```

开局消息会显示本局的题库范围。已有对局时再次开局，只会重发当前题目；想换范围，请先结束本局。

## 提交猜测与提示

```text
/我猜宝可梦剪影是 皮卡丘
```

支持中文名、英文名、日文名、已收录的别名、拼音及模糊匹配。请使用完整猜测指令，普通聊天中的宝可梦名称不会自动提交。

- 可以重复猜同一种宝可梦，每次有效猜测都会计入本局次数。
- 没有匹配到宝可梦的输入不算有效猜测。
- 猜中或主动结束时会公布答案，并汇总本局猜测次数。
- 猜中后不会自动开下一局，可以重新开局或点击「再来一局」。

一时想不起来也没关系，用 `/宝可梦猜剪影提示` 找幽幽子要点线索：

| 本局范围 | 提示顺序 |
| --- | --- |
| 全部题库 | 先提示世代，再提示属性 |
| 指定世代 | 只提示属性 |

线索发完了也不会自动揭晓，谜底会继续等你来猜；想看答案就用 `/结束宝可梦猜剪影`。获取提示不计入猜测次数。

## 结束与战绩

群内任何成员都可以结束本局。提交过有效猜测的玩家和主动结束者都会计参与局数；**主动结束不计胜场**。

用 `/宝可梦猜剪影战绩` 翻翻自己的猜谜成绩：

| 项目 | 怎么算 |
| --- | --- |
| 最终胜场 | 由你提交正确答案的对局 |
| 参与胜场 | 你提交过有效猜测，而且最后被大家猜中的对局 |
| 参与局数 | 提交过有效猜测，或由你主动结束的对局，同一局只记一次 |
| 活跃天数 | 有效参与并结算过对局的天数，按北京时间计算，同一天只记一次 |

开局、获取提示、查看帮助和无效猜测不算有效参与。战绩与属性推理玩法的「猜宝可梦」分别记录。
