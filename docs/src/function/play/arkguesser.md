# 明日方舟猜干员

## 概述

博士，来认认这位干员吧～每局会选出一位干员，职业、星级、身高等九项属性都是线索。**每局共有 10 次有效猜测机会**，群友们共用，可以一起推理；私聊也可以单人游玩。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/猜干员 (星级或范围)` | 开始游戏，默认四至六星 |
| `/我猜干员是 [名称或别名]` | 提交猜测 |
| `/结束猜干员` | 结束本局并揭晓答案，不计战绩 |
| `/猜干员 帮助` | 查看玩法和开局参数 |
| `/猜干员战绩` | 查看个人战绩 |

开局也支持 `/arkstart`、`/明日方舟开始`。同一会话已有游戏时，再次开局不会更换答案或星级范围。

## 选择星级

```text
/猜干员
/猜干员 5
/猜干员 4-6
```

- 不填参数时，从四至六星干员中选择答案。
- 单个星级可填 3～6；范围的两个端点可填 1～6，并且必须包含三星或更高星级。
- 不能只选择一星、二星或一至二星范围。
- 星级范围只限制**答案**，猜测时仍可填写题库内其他星级的干员。

想换个星级范围试试？先结束当前对局就好。结算后的「再玩一次」会沿用本局范围；手动发送不带参数的 `/猜干员`，则回到四至六星。

## 提交猜测

```text
/我猜干员是 阿米娅
```

支持正式名称、已收录的简称与别名。较长名称有少量错字、增字或漏字时，也会尝试匹配唯一对应的干员；短简称、拼音或同音字不保证能识别，找不到时请改用正式名称。

阿米娅目前按术师形态参与猜测；其他职业形态不会自动当作术师形态提交。

- 无效、未能明确匹配或重复猜测不消耗机会。
- 同一干员换个别名提交，也算重复猜测。
- 第 10 次猜中仍算获胜；用完机会还未猜中时，会自动揭晓答案。
- 看一眼反馈图里的正式干员名，确认幽幽子认的是你想猜的那位哦。

## 怎么看线索

| 线索 | 比较内容 |
| --- | --- |
| 职业／分支 | 职业和分支都相同为绿色，只有主职业相同为黄色 |
| 星级 | 相等为绿色，箭头指向答案的星级 |
| 身高 | 明确身高相等为绿色，相差不超过 5 厘米为黄色；无法比较时显示灰色 |
| 出身地 | 比较所属地点 |
| 种族 | 比较种族 |
| 性别 | 比较性别 |
| 部署位置 | 比较近战位、远程位等部署类型 |
| 势力 | 主势力和子势力都相同为绿色，只匹配主势力为黄色 |
| 标签 | 完全相同为绿色，部分重合为黄色 |

红色表示不匹配。星级和身高的箭头指的是**答案相对本次猜测**的方向：向上更高，向下更低。

身高缺失、约数或同时包含多种姿态时会显示灰色，不要把灰色当作已匹配。

## 结束与战绩

想知道是哪位干员了？用 `/结束猜干员` 揭晓答案，不过**主动结束不计战绩**。自然猜中或用完机会后，才会为提交过有效猜测的玩家结算。

用 `/猜干员战绩` 翻翻成绩单，里面有最终胜场、参与胜场、参与局数和活跃天数。自己猜中计最终胜场；帮忙猜过、且本局最终获胜的玩家，也有参与胜场哦。

同一局参与只记一次，活跃天数按北京时间计算，同一天只记一次。开局、查看帮助、无效猜测或只点击结束，不算有效参与。
