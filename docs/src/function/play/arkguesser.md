# 明日方舟猜干员

## 概述

博士，来认认这位干员吧～大头模式看背景属性，兔头模式看战斗数值。**每局共有 10 次有效猜测机会**，群友们共用；私聊也可以单人游玩。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/猜干员 (星级或范围)` | 开始大头模式，默认四至六星 |
| `/猜干员 兔头 (星级或范围)` | 开始战斗数值模式，默认四至六星 |
| `/我猜干员是 [名称或别名]` | 提交猜测 |
| `/结束猜干员` | 结束本局并揭晓答案，计参与局数、不加胜场 |
| `/猜干员 帮助` | 查看玩法和开局参数 |
| `/猜干员战绩` | 同时查看大头、兔头两种模式的个人战绩 |

开局也支持 `/arkstart`、`/明日方舟开始`。同一会话已有游戏时，再次开局只会展示进度，不会更换答案、模式或星级范围。

## 选择模式与星级

```text
/猜干员
/猜干员 5
/猜干员 4-6
/猜干员 兔头
/猜干员 兔头 5
/猜干员 大头 4-6
```

- 不填模式或星级时，使用大头模式、四至六星；只填「兔头」也默认四至六星。
- 单个星级可填 3～6；范围的两个端点可填 1～6，按从小到大书写，并且必须包含三星或更高星级。
- 不能只选择一星、二星或一至二星范围。
- 支持全角数字和常见范围符号，例如 `/猜干员 ４ ～ ６`。
- 星级范围只限制**答案**，猜测时仍可填写题库内其他星级的干员。

想换个模式或范围试试？先结束当前对局就好。结算后的「再玩一次」会沿用本局模式与范围；手动发送不带参数的 `/猜干员`，则回到大头模式、四至六星。

## 提交猜测

```text
/我猜干员是 阿米娅
```

正式名称和已收录的简称、别名优先匹配；没有精确命中时，也会尝试匹配相近名称。没有明确结果时，请改用正式名称；拼音、同音字和职业限定不保证能表达你想猜的形态。

阿米娅目前按术师形态参与猜测，不能通过附加职业文字选择尚未收录的其他形态。

- 无效、未能明确匹配或重复猜测不消耗机会。
- 同一干员换个别名提交，也算重复猜测。
- 第 10 次猜中仍算获胜；用完机会还未猜中时，会自动揭晓答案。
- 看一眼反馈图里的正式干员名，确认识别成了你想猜的那位哦。

## 怎么看线索

绿色和 `✓` 表示相同，黄色和 `≈` 表示部分匹配或数值接近，红色和 `×` 表示不同。箭头指的是**答案相对本次猜测**的方向：向上更高，向下更低。灰色表示未知，不能当作已经匹配。

### 大头模式

| 线索 | 比较内容 |
| --- | --- |
| 职业／分支 | 职业和分支都相同为绿色，只有主职业相同为黄色 |
| 星级 | 相等为绿色，箭头指向答案的星级 |
| 感染状态 | 感染者／非感染者，相同为绿色，未知为灰色 |
| 种族 | 比较种族 |
| 性别 | 比较性别 |
| 部署位置 | 比较近战位、远程位等部署类型 |
| 势力 | 主势力和子势力都相同为绿色，只匹配主势力为黄色 |
| 标签 | 完全相同为绿色，部分重合为黄色 |

大头模式不再比较身高和出身地。感染状态未公开或无法明确判断时显示「未知」；即使双方都未知，也不算匹配。

### 兔头模式

| 线索 | 比较内容 |
| --- | --- |
| 星级 | 相等或高低 |
| 满级攻击 | 攻击面板 |
| 满级生命 | 生命面板 |
| 满级防御 | 防御面板 |
| 满级法抗 | 法术抗性 |
| 攻击间隔 | 基础攻击间隔 |
| 上线年份 | 干员上线年份 |
| 标签 | 完全相同或部分重合 |

面板取最高可用精英阶段的满级、满潜能和满信赖数值，**不计算天赋、技能、模组或潜能攻速加成**；攻击间隔使用基础值。

- 面板和攻击间隔相同为绿色；通常与答案相差不超过 10% 为黄色，答案数值小于 10 时改为差值不超过 1。
- 上线年份同年为绿色，相差不超过 3 年为黄色；不同年份仍会显示早晚箭头。
- 星级只比较相同或高低，不使用接近色。缺少数值时显示灰色，已知的 0 法抗可以正常比较。

## 结束与战绩

群内任何成员都可以使用 `/结束猜干员` 揭晓答案。已有有效参与者和主动结束者都会计入参与局数，**主动结束不增加胜场**。

使用 `/猜干员战绩`，一条回复会分别显示「大头」与「兔头」的四项战绩，两种模式独立记录：

| 项目 | 怎么算 |
| --- | --- |
| 最终胜场 | 由你提交正确答案的对局 |
| 参与胜场 | 你提交过有效猜测，而且最后被大家猜中的对局 |
| 参与局数 | 你有效参与或主动结束的对局，同一局只记一次 |
| 活跃天数 | 有参与结算的天数，按北京时间计算，同一天只记一次 |

只开局、查看进度、查看帮助或无效猜测不算参与；主动结束者按上面的规则计入。
