# 猜洛克精灵

## 概述

有只精灵藏起来了，来把它找出来吧～每局会选出一只《洛克王国：世界》的精灵，顺着七项属性线索，一点点缩小范围。每局共有 **10 次有效猜测机会**，群友们共用；也可以私聊，自己慢慢推理。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/猜洛克` | 开始基础形态模式 |
| `/猜洛克 全形态` | 从全部形态中选择答案 |
| `/我猜洛克是 [精灵名]` | 提交猜测 |
| `/结束猜洛克` | 结束本局并揭晓答案 |
| `/猜洛克帮助` | 查看玩法说明 |
| `/猜洛克战绩` | 查看个人战绩 |

开局也支持 `/猜洛克精灵`。同一群聊共用一局，已有对局时再次开局只会展示当前进度，不会更换答案或模式。

基础模式只从基础形态中选择答案，全形态模式也会选到其他形态或首领形态。**模式只限制答案范围**，两种模式都可以提交题库内的其他形态作为猜测。

## 提交猜测

```text
/我猜洛克是 霜翼领主
```

想好猜谁了？正式名称、形态名、已收录的外号或无声调拼音都可以试试，幽幽子也会尝试匹配相近的名称。记得带上 `/我猜洛克是`，只发名字不会提交猜测哦。

- 无效或重复猜测不消耗机会；同一只精灵换个别名也不会变成新的猜测。
- 猜中目标，或七项属性全部匹配，即可获胜。
- 第 10 次猜中仍然算赢；用完机会还未猜中时，会自动揭晓答案。
- 图中会显示实际识别到的精灵名称，名字不太确定时记得检查一下。

## 怎么看线索

| 线索 | 比较内容 |
| --- | --- |
| 系别 | 完全相同为绿色，部分系别重合为黄色 |
| 总种族值 | 相等为绿色，相差不超过 15 为黄色；箭头指向答案的数值 |
| 速度 | 相等为绿色，相差不超过 5 为黄色；箭头指向答案的数值 |
| 攻防 | 比较物攻与魔攻、物防与魔防的大小关系；两组关系相同为绿色，一组相同为黄色 |
| 阶段 | 比较一阶、二阶和最终形态；相同为绿色，相邻为黄色，并提示方向 |
| 蛋组 | 完全相同为绿色，部分重合为黄色；缺少资料时显示灰色 |
| 特殊形态 | 比较是否有异色，以及基础、其他或首领形态；两项相同为绿色，一项相同为黄色 |

红色表示不匹配。反馈图还会用 `✓`、`≈`、`×` 标识完全匹配、部分匹配和不匹配。箭头指的是**答案相对这次猜测**的方向：向上表示答案更高，向下表示答案更低。

蛋组中的「未发现」是有效类别，「未知」才是缺少资料；灰色线索不能当作已经匹配。

## 结束与战绩

想揭开谜底了？群内任何成员都可以使用 `/结束猜洛克`。已有有效参与者和主动结束者都会计入参与局数，**主动结束不增加胜场**。自然猜中或用完机会时，也会为提交过有效猜测的玩家结算。

用 `/猜洛克战绩` 翻翻自己的成绩单：

| 项目 | 怎么算 |
| --- | --- |
| 最终胜场 | 由你完成最后一次正确猜测的对局 |
| 参与胜场 | 你提交过有效猜测，而且最后被大家猜中的对局 |
| 参与局数 | 提交过有效猜测，或由你主动结束的对局，同一局只记一次 |
| 活跃天数 | 有效参与并结算过对局的天数，按北京时间计算，同一天只记一次 |

基础与全形态模式共用战绩。开局、查看进度或无效猜测不算有效参与；主动结束者按上面的规则计入。
