# 今日猪猪

## 概述

今天会遇到哪只小猪？每天来抓一只，慢慢填满自己的猪圈吧～

## 指令

### 抽猪猪

- 指令： `今日猪猪`

- 别名： `/今日猪猪`

- 详情：

  查看今日猪猪

### 我的猪圈

- 指令： `我的猪圈`

- 别名： `我的猪圈统计`、`猪猪图鉴`、`猪圈`

- 详情：

  查看我的猪圈

### 猪猪详情

- 指令： `猪猪详情 [名称]`

- 别名： `/猪猪详情 [名称]`

- 参数：

  - `名称`： 图鉴中的完整猪猪名称，目前不支持简称或模糊搜索

- 详情：

  查看自己已经抓到的猪猪详情，包括图片、名称、介绍和解读，以及当前等级、累计获得次数和首次获得日期。

- 使用示例：

  ```text
  /猪猪详情 猪卖萌
  ```

## 使用提示

- 支持点击的平台可以直接点击「今日猪猪」里的猪猪名称查看详情，也可以从「我的猪圈」打开查询入口。
- 详情只查询自己已经获得的猪猪，尚未拥有时不会展示完整详情。
- 不记得完整名称时，可以先翻翻自己的猪圈，再复制名称查询。
