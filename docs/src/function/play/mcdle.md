# MC 猜谜

## 概述

MC 猜谜（MCDLE）会从 Minecraft 的生物、方块或物品中选择一个答案。每次提交猜测后，机器人会比较猜测与答案的各项属性，帮助你逐步排除错误选项。

游戏没有固定的猜测次数限制，可以一直尝试到猜中或主动结束。

## 开始游戏

| 指令 | 效果 |
| --- | --- |
| `/猜MC生物` | 开始一局生物猜谜 |
| `/猜MC方块` | 开始一局方块猜谜 |
| `/猜MC物品` | 开始一局物品猜谜 |

同一个群聊或私聊同时只能进行一局 MC 猜谜。需要切换类别时，请先结束当前游戏。

三种模式会比较不同信息：

| 模式 | 主要比较内容 |
| --- | --- |
| 生物 | 生命值、行为、生成方式、分类、高度、加入版本等 |
| 方块 | 可再生性、合适工具、亮度、透明度、硬度、爆炸抗性、加入版本等 |
| 物品 | 可再生性、堆叠、稀有度、获取方式、用途、配方、加入版本等 |

## 提交猜测

- 指令：`/我猜MC是 [名称]`

例如：

```text
/我猜MC是 苦力怕
```

可以使用对应类别的中文名、英文名或常见别名。输入有少量差异时也会尝试查找最接近的名称；如果没有找到，可以改用游戏中的正式名称。

每次猜测后会显示属性对比：

| 提示 | 含义 |
| --- | --- |
| 🟩 | 与答案完全一致 |
| 🟨 | 部分内容与答案重合 |
| 🟥 | 与答案不一致 |
| 🟥⬆️ | 答案的数值或版本更高 |
| 🟥⬇️ | 答案的数值或版本更低 |

已经猜过的名称不会重复计入。

## 结束游戏

- 指令：`/结束猜MC`

结束当前游戏并揭晓答案。

## 查看战绩

- 指令：`/猜MC战绩`

查看自己的总胜场，以及生物、方块和物品三种模式各自的胜场。只有成功猜中的对局会计入战绩。

## 玩法帮助

- 指令：`/猜MC帮助`
- 别名：`/猜MC菜单`

查看玩法说明，并在支持按钮的平台上直接选择游戏类别。
