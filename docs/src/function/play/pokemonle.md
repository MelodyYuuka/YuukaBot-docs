# 猜宝可梦

## 概述

皮卡丘？伊布？还是藏在记忆角落里的那一只？来凭线索认认宝可梦吧~

猜宝可梦（Pokemonle）每局有 **10 次机会**。每猜一次，都会得到一张属性对照表，顺着线索慢慢缩小范围就好。

## 开始游戏

- 指令：`/猜宝可梦`

同一个群聊共用一局，大家可以一起猜；私聊里则是自己的对局。已经有游戏在进行时，要先猜完或结束，才能再开一局。

不知道先猜谁？开局消息会给出一个随机示例，可以从它开始试试。

## 提交猜测

- 指令：`/我猜宝可梦是 [名称]`

例如：

```text
/我猜宝可梦是 皮卡丘
```

支持中文名、英文名、日文名和已收录的常见别名。名字有少量差异时，也会尝试匹配最接近的宝可梦；记得看看表格里识别成了谁哦。

线索包括属性、种族值、速度、攻防、世代、特性、进化阶段、外形与颜色、捕获率和标签。

| 提示 | 含义 |
| --- | --- |
| 🟩 | 与答案完全匹配 |
| 🟨 | 部分匹配 |
| 🟥 | 不匹配 |
| ⬆️ | 答案对应的数值更高 |
| ⬇️ | 答案对应的数值更低 |

:::tip
箭头指的是**答案**相对你这次猜测的方向，不是让你改哪一个字~

已经猜过的宝可梦不会重复消耗机会。空输入或没有匹配到宝可梦，也不会扣次数。
:::

## 结束游戏

- 指令：`/结束猜宝可梦`

想看答案了？结束本局就会揭晓。猜中或用完机会时，也会自动公布答案。

## 查看战绩

- 指令：`/猜宝可梦战绩`

| 项目 | 怎么算 |
| --- | --- |
| 最终胜场 | 由你提交最后一次正确答案的对局 |
| 参与胜场 | 你提交过有效猜测，而且最后被大家猜中的对局；自己猜中的也算 |
| 参与局数 | 提交过有效猜测的对局，同一局不重复计数 |
| 活跃天数 | 有过有效猜测的日期，按北京时间计算，同一天只记一次 |

不一定要抢到最后一击，一起帮忙找线索也有记录啦~

## 玩法帮助

- 指令：`/猜宝可梦帮助`

忘记颜色和箭头的含义时，可以随时翻翻帮助。
