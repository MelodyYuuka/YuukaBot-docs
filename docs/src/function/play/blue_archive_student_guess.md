# 猜 BA 学生

## 概述

来认认《蔚蓝档案》的学生吧～每局共有 **6 次有效猜测机会**，根据六项属性逐步缩小范围。群聊里的玩家共用一局，也可以私聊单人游玩。

可以选择国服、国际服或日服的已实装学生，**默认国服**。不同服装分别参与猜谜，需要认出具体的那一位。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/猜ba学生 (区服)` | 开始游戏，默认国服 |
| `/我猜ba学生是 [学生名或别名]` | 提交猜测 |
| `/结束猜ba学生` | 结束本局并揭晓答案 |
| `/猜ba学生帮助` | 查看玩法说明 |
| `/猜ba学生战绩` | 查看个人战绩 |

开局也支持 `/猜ba`、`/猜BA`、`/猜蔚蓝档案学生`；上述常用指令也支持不带 `/` 的写法。

## 选择区服

```text
/猜ba学生
/猜ba学生 国际服
/猜ba学生 日服
/猜ba学生 国服
```

已有对局时，不带参数或指定同一区服只会展示当前进度，不会更换答案。想换区服，需要先结束本局；结算后的「再来一局」会保留本局区服。

## 提交猜测

```text
/我猜ba学生是 爱露
/我猜ba学生是 日奈（礼服）
/我猜ba学生是 水日奈
```

正式名称、已收录的中文昵称、英文名和服装别名都可以使用，也会尝试匹配相近名称。没有明确匹配时，请改用包含服装的完整名称。

- 无效、歧义和重复猜测不消耗机会；同一学生换个别名仍算重复。
- 不同服装是不同答案，例如日奈和日奈（礼服）不能互相代替。
- **需要猜中具体学生**，六项属性碰巧全部相同也不能代替名称判断。
- 第 6 次猜中仍算获胜；用完机会后会自动揭晓答案。终局还会展示答案立绘。

## 怎么看线索

| 线索 | 比较内容 |
| --- | --- |
| 学校 | 学生所属学校 |
| 战术角色 | 学生的战术定位，如坦克、输出等 |
| 攻击类型 | 攻击类型，不是防御类型 |
| 武器类型 | 使用的武器类别 |
| EX 费用 | EX 技能 1 级时的费用 |
| 实装顺序 | 学生的统一实装序号，不是当前区服的上线日期或顺序 |

绿色和 `✓` 表示相同，红色和 `×` 表示不同。EX 费用和实装顺序还会给出箭头：向上表示答案的数值更大，向下表示更小。

## 结束与战绩

群内任何成员都可以使用 `/结束猜ba学生` 揭晓答案。提交过有效猜测的玩家会计参与局数，**主动结束不计胜场**；没有有效猜测的空局不计战绩。

使用 `/猜ba学生战绩` 查看：

| 项目 | 怎么算 |
| --- | --- |
| 最终胜场 | 由你提交正确答案的对局 |
| 参与胜场 | 你提交过有效猜测，而且最后被大家猜中的对局 |
| 参与局数 | 提交过有效猜测并结束的对局，主动结束也算 |
| 活跃天数 | 有效参与并结算过对局的天数，按北京时间计算，同一天只记一次 |

三个区服共用个人战绩。只开局、查看进度、无效猜测或只点击结束，不算有效参与。
