# PJSK 猜卡面

## 概述

卡面糊成这样，还能一眼认出你的推吗？

每局会从 PJSK 的三星、四星卡面中抽一张，随机加上模糊、打乱或截取效果。**猜角色就好，不用报出卡牌名字**，花前、花后都有可能出现哦~

## 开始游戏

- 指令：`/猜pjsk卡面`

一局共有 **8 次机会**。同一个群聊共用一局和猜测次数，大家可以一起认；私聊也能玩。

## 提交猜测

- 指令：`/我猜pjsk卡面是 [角色名]`

例如：

```text
/我猜pjsk卡面是 咲希
```

中文名、英文名、缩写和已收录的常见别名都可以。不确定名字有没有被认出来时，看看回复里的角色名就好。

:::warning
重复猜同一位角色也会消耗次数，别对着同一个名字连猜十次呀！

空输入、过长的名字或没有识别到角色时，不消耗机会。
:::

## 效果与得分

不同效果有不同的基础分：

| 效果 | 基础分 |
| --- | --- |
| 轻度模糊 | 1 |
| 重度模糊 | 2 |
| 分块打乱（简易） | 1 |
| 分块打乱（困难） | 3 |
| 横向切割、纵向切割 | 各 1 |
| 截取区域 | 1 |
| 三长条截取、四长条截取 | 各 2 |

猜中的玩家获得 **基础分 × 次数倍率**：

| 本局第几次猜中 | 倍率 |
| --- | --- |
| 第 1 次 | ×3 |
| 第 2～3 次 | ×2 |
| 第 4 次及以后 | ×1 |

这里算的是**本局所有人的累计有效猜测次数**，不是每个人单独算。例如，大家前面已经猜了两次，你接着猜中，就是本局第 3 次，拿到 2 倍基础分。

## 切换题库

默认使用**国服题库**，也可以换成日服：

| 指令 | 效果 |
| --- | --- |
| `/猜pjsk卡面切换日服题库` | 改用日服题库 |
| `/猜pjsk卡面切换国服题库` | 改用国服题库 |

群聊中切换的是本群题库，私聊中切换的是自己的题库，均从**下一局**生效。切换成功后会显示题库卡面数量与数据版本。

## 结束游戏

- 指令：`/结束猜pjsk卡面`

结束当前对局，揭晓角色与完整卡面。猜中或机会用完时，也会自动揭晓。

## 查看战绩

- 指令：`/猜pjsk卡面战绩`

可以查看总分、参与局数、答对局数、参与胜场和正确率。

- **答对**：由你猜中角色的对局。
- **参与胜场**：你提交过有效猜测，最后被大家猜中的对局，包含你自己答对的局。
- **正确率**：答对局数 ÷ 参与局数。

战绩在对局结束时结算。

## 玩法帮助

- 指令：`/猜pjsk卡面帮助`

查看当前题库、效果说明和计分规则。
