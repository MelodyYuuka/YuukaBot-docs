# 词影猜成语

## 概述

词影是一个根据汉字笔画猜四字成语的游戏，玩家需要在6次猜测内猜出答案。

每次猜测后，bot会按位置比较猜测与答案的汉字笔画。青色笔画表示高度相似，灰色影子表示部分相似。

普通模式会累积每次猜测产生的笔画影子；困难模式只显示本次猜测的比较结果。提示会显示已经准确猜中的位置。

## 指令

### 开始词影

- 指令： `/词影 [模式]`

- 别名： `/ciying`、`/笔画猜成语`

- 参数：

  - `模式`：可选，使用 `困难`、`hard` 或 `--hard` 开启困难模式，默认为普通模式

- 详情：

  开始一局词影游戏

### 提示词影

- 指令： `/提示词影`

- 别名： `/提示ciying`

- 详情：

  查看已经准确猜中的位置

### 结束词影

- 指令： `/结束词影`

- 详情：

  结束当前词影游戏并查看答案

### 我猜词影是

- 指令： `/我猜词影是 [成语]`

- 别名： `/ciyingguess`

- 参数：

  - `成语`：猜测的四字成语

- 详情：

  猜测成语，获取笔画比较结果

### 使用词影帮助

- 指令： `/使用词影帮助`

- 详情：

  获取词影游戏的帮助信息

## 我的战绩

- 指令：`/词影战绩`
- 别名：`/ciying战绩`

这次又认出了几个熟悉的字？自己的猜谜成绩可以在这里查看。

| 项目 | 计算方式 |
| --- | --- |
| 最终胜场 | 自己提交最后一次正确答案、让本局获胜的次数 |
| 参与胜场 | 本局提交过有效猜测，且大家最终猜中的次数，包含自己收尾的对局 |
| 参与局数 | 提交过有效猜测的对局数，同一局只记一次 |
| 活跃天数 | 有效参与过游戏的天数，按北京时间计算，每天只记一次 |

只是开局或查看帮助不会增加参与记录。支持按钮的平台还可以点击「我的战绩」，不用再翻指令。
