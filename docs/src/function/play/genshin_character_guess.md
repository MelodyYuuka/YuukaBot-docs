# 猜原神角色

## 概述

旅行者，来猜猜提瓦特的熟面孔吧～每局会选出一名原神角色，从地区、元素到培养材料，七项属性线索帮你一点点找出答案。**每局共有 10 次有效猜测机会**，群友们共用；私聊也可以单人游玩。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/猜原神` | 开始游戏 |
| `/我猜原神是 [角色名]` | 提交猜测 |
| `/结束猜原神` | 结束本局并揭晓答案 |
| `/猜原神帮助` | 查看玩法说明 |
| `/猜原神战绩` | 查看个人战绩 |

开局、结束、帮助和战绩也支持不带 `/` 的写法。猜测时记得使用 `/我猜原神是`，平时聊天只提到角色名字，不会被当成答案哦。

已有对局时再次开局只会展示当前进度，不会更换答案。猜中或用完机会后，再开局开始下一题。

## 提交猜测

```text
/我猜原神是 阿贝多
/我猜原神是 小草神
```

正式中文名和已收录的别名都可以使用，名字有少量差异时也会尝试模糊匹配。

| 角色 | 别名示例 |
| --- | --- |
| 雷电将军 | 雷神、将军、Raiden Shogun |
| 达达利亚 | 公子、达达鸭、Childe |
| 纳西妲 | 草神、小草神、小吉祥草王 |
| 芙宁娜 | 水神、芙芙、Furina |
| 钟离 | 岩王爷、岩王帝君、帝君 |

昵称或相近写法有时会让幽幽子认不准是哪位角色，这时会先给出候选正式名称，不会自动提交；例如「神里」还需要分清是神里绫人，还是神里绫华。

- 无效、歧义和重复猜测不消耗机会。
- 同一角色换个别名提交，仍然算重复猜测。
- 第 10 次猜中仍算获胜；用完机会还未猜中时，会自动揭晓答案。
- 不会自动把拼音转换成角色名。直接写名称就好，不要附加一整句话；也记得看看反馈图，确认认对了角色。

## 怎么看线索

| 线索 | 比较内容 |
| --- | --- |
| 地区 | 角色所属地区 |
| 元素 | 角色使用的元素 |
| 武器 | 武器类型 |
| 上线年份 | 角色上线的年份 |
| 生日月份 | 生日所在月份 |
| 普通材料 | 角色使用的普通培养材料 |
| 天赋书 | 角色使用的天赋书 |

绿色和 `✓` 表示与答案相同，红色和 `×` 表示不同。上线年份和生日月份还会给出方向：

| 提示 | 含义 |
| --- | --- |
| ⬆️ | 答案的年份更晚，或月份数字更大 |
| ⬇️ | 答案的年份更早，或月份数字更小 |

生日月份直接按 1～12 的数字大小比较，不按跨年距离比较。

## 结束与战绩

群内任何成员都可以使用 `/结束猜原神` 揭晓答案。提交过有效猜测的玩家会计参与局数，**主动结束不计胜场**。

用 `/猜原神战绩` 看看自己的猜谜成果：

| 项目 | 怎么算 |
| --- | --- |
| 最终胜场 | 由你提交正确答案的对局 |
| 参与胜场 | 你提交过有效猜测，而且最后被大家猜中的对局 |
| 参与局数 | 提交过有效猜测并结束的对局，主动结束也算 |
| 活跃天数 | 有效参与并结算过对局的天数，按北京时间计算，同一天只记一次 |

开局、查看进度或帮助、无效猜测，以及只点击结束而没有猜过，都不算有效参与。
