# Math 猜等式

## 概述

Mathle 是一个根据颜色线索猜等式的游戏。答案由数字、运算符和一个等号组成，等号两边的计算结果必须相同。

每次猜测后，格子会给出颜色提示：

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 数字或符号正确，位置也正确 |
| 黄色 | 数字或符号存在，但位置不对 |
| 灰色 | 没有匹配，或答案中对应符号的数量已经用完 |

重复的数字和符号会严格按照答案中的实际数量判定。

## 开始游戏

- 指令：`/猜等式 (长度) (棋盘数量) (模式)`
- 别名：`/mathle`

| 参数 | 用法 |
| --- | --- |
| 长度 | 可选 5～12；不填写时随机选择 |
| 棋盘数量 | 使用 `x1`～`x4`，默认为 `x1` |
| 模式 | 可填写 `困难` 或 `超困难`，不填写时为普通模式 |

例如：

| 指令 | 效果 |
| --- | --- |
| `/猜等式` | 随机长度的单棋盘普通模式 |
| `/猜等式 8` | 长度为 8 的单棋盘游戏 |
| `/猜等式 8 x2` | 同时猜两个长度为 8 的等式 |
| `/猜等式 8 困难` | 长度为 8 的困难模式 |
| `/猜等式 10 x3 超困难` | 同时挑战三个长度为 10 的超困难棋盘 |

单棋盘有 6 次猜测机会；每增加一个棋盘，会增加 1 次机会。多棋盘共用每次猜测，需要在机会用完前找出所有答案。

## 游戏模式

| 模式 | 规则 |
| --- | --- |
| 普通 | 可以自由尝试任何成立的等式 |
| 困难 | 已经变绿的位置必须保持不变，黄色符号必须继续使用 |
| 超困难 | 除困难规则外，黄色符号不能留在原位置，已经确认不存在的符号也不能再使用 |

多棋盘困难模式中，不同答案给出的线索可能互相冲突。遇到无法继续的情况时，可以结束后重新开局。

## 提交猜测

- 指令：`/我猜等式是 [等式]`
- 别名：`/mathguess`

等式只能使用 `0-9`、`+`、`-`、`*`、`/` 和 `=`，并且只能有一个等号。`×` 和 `÷` 也可以使用。

等式长度会计算每一个数字和符号。例如 `6+1=7` 的长度是 5。机器人只接受左右两边结果确实相等的等式。

## 查看提示

- 指令：`/提示等式`
- 别名：`/提示Math`、`/提示math`

查看各棋盘已经确定的绿色位置，尚未确定的位置会显示为星号。

## 结束游戏

- 指令：`/结束等式`
- 别名：`/结束Math`、`/结束math`

结束当前游戏并揭晓全部答案。
