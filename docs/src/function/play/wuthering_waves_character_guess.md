# 猜鸣潮

## 概述

来认认《鸣潮》的共鸣者吧～每局共有 **8 次有效猜测机会**，根据六项属性寻找答案。群聊里的玩家共用一局，也可以私聊单人游玩；不是每天固定一题，结束后可以继续开新局。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/猜鸣潮` | 开始游戏；已有对局时查看进度 |
| `/我猜鸣潮是 [共鸣者名或别名]` | 提交猜测 |
| `/结束猜鸣潮` | 结束本局并揭晓答案 |
| `/猜鸣潮帮助` | 查看玩法说明 |
| `/猜鸣潮战绩` | 查看个人战绩 |

以上指令也支持不带 `/` 的写法。已有对局时再次开局只会展示当前进度，不会更换答案。开局会给出一个随机猜测示例，不知道先猜谁时可以从它开始。

## 提交猜测

```text
/我猜鸣潮是 长离
/我猜鸣潮是 Phrolova
/我猜鸣潮是 漂泊者(气动)
```

支持正式名称、已收录的别名和英文名，也会尝试匹配相近名称。遇到歧义时，会先提示可选的正式名称，不会直接提交。

- 漂泊者按属性分别猜测，同一属性的男女漂泊者合为一项，性别显示「可选」。只输入「漂泊者」或「Rover」时，需要再明确属性。
- 无效、歧义和重复猜测不消耗机会；同一角色换个别名仍算重复。
- 需要猜中具体共鸣者，六项属性碰巧全部相同也不能代替名称判断。
- 第 8 次猜中仍算获胜；用完机会后会自动揭晓答案。
- 普通聊天里只提到名字不会提交猜测，记得使用完整指令哦。

## 怎么看线索

| 线索 | 比较内容 |
| --- | --- |
| 星级 | 共鸣者星级 |
| 属性 | 冷凝、热熔、导电、气动、衍射或湮灭 |
| 武器 | 长刃、迅刀、佩枪、臂铠或音感仪 |
| 性别 | 包括漂泊者的「可选」 |
| 定位 | 生存治疗、主力输出、快速协奏，可同时有多项 |
| 战斗特性 | 共鸣者的战斗特性标签，逐项比较 |

| 提示 | 含义 |
| --- | --- |
| 🟩／`✓` | 完全相同 |
| 🟨／`≈` | 定位或战斗特性有部分重合 |
| 🟥／`×` | 不同 |
| 灰色 | 未知信息，不能当作已经匹配 |

星级、属性、武器和性别只比较是否相同，**没有高低箭头**。定位与战斗特性可能有多项，请看完整标签，不要只看第一项；「无额外标签」是有效结果，不等于未知。

## 结束与战绩

群内任何成员都可以使用 `/结束猜鸣潮` 揭晓答案。提交过有效猜测的玩家会计参与局数，**主动结束不计胜场**；没有有效猜测的空局不计战绩。

使用 `/猜鸣潮战绩` 查看最终胜场、参与胜场、参与局数和活跃天数。由你猜中才增加最终胜场；有效参与过、且最终获胜的对局会增加参与胜场。活跃天数按北京时间的结算日期计算，同一天只记一次。

只开局、查看进度、无效猜测或只点击结束，不算有效参与。
