# 人生重开模拟器

## 概述

这人生一秒也待不下去了！那就选好天赋，重开一场人生吧。

这次是平平淡淡过一生，还是活到让人怀疑年龄的程度？除了看故事，也可以慢慢收集天赋、事件和成就。

## 开始重开

- 指令：`/人生重开`
- 别名：`人生重开！`、`/remake`

### 选择天赋

机器人会给出 10 个天赋，从中挑选 **3 个不同的天赋**，发送对应编号，用空格隔开：

```text
0 1 2
```

不想纠结就发送 `随机`。有些天赋不能一起选择，遇到提示时重新搭配即可。

### 分配属性

按 **颜值、智力、体质、家境** 的顺序发送四个数字。每项可以分配 0～10 点，总点数以本次提示为准，部分天赋会影响可分配点数。

例如，提示可以分配 20 点时，可以发送：

```text
5 5 5 5
```

这里也可以发送 `随机`，把开局交给命运。

:::tip
选择天赋和分配属性时都可以发送 `取消` 退出，不用勉强过上这辈子~
:::

完成设置后，就可以看这一生的经历和最终评价了。结束时还会告诉你本局打破了哪些纪录、收集到了什么，以及有没有解锁新成就。

## 人生统计

- 指令：`/人生统计`

翻翻自己的重开小档案：

- 累计重开次数、最高寿命、最佳总评
- 颜值、智力、体质、家境和快乐的最高纪录
- 天赋、事件与成就的收集进度

## 人生成就

- 指令：`/人生成就 (分类) (筛选) (页码)`

不加参数时查看成就总览；想找下一颗没点亮的星星，可以用分类和筛选慢慢翻。

| 参数 | 可填写内容 |
| --- | --- |
| 分类 | `重开次数`、`人生纪录`、`天赋际遇`、`事件经历`、`跨局收集` |
| 筛选 | `全部`、`已解锁`、`未解锁` |
| 页码 | 从 1 开始的整数 |

例如：

```text
/人生成就
/人生成就 未解锁
/人生成就 跨局收集 已解锁 1
```

有些是隐藏成就，解锁前不会告诉你它的名字，留一点惊喜给下一次重开。

:::info
统计、纪录和收集进度从这些功能上线后开始累计，之前的人生没办法补算。就从下一次重开开始攒吧。
:::
