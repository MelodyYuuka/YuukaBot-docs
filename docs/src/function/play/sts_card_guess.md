# 猜塔卡牌

## 概述

来用卡牌知识挑战一下自己吧～每局共有 **8 次有效猜测机会**，从《杀戮尖塔》一代与二代的混合题库中选择答案。

想查卡牌效果，可以另用 [杀戮尖塔图鉴](../query/sts.md)。

## 常用指令

| 指令 | 短指令 | 用途 |
| --- | --- | --- |
| `/猜塔卡牌` | `/猜塔` | 开始游戏；已有对局时查看进度 |
| `/我猜塔卡牌是 [卡名]` | `/我猜塔是 [卡名]` | 提交猜测 |
| `/结束猜塔卡牌` | `/结束猜塔` | 结束本局并揭晓答案 |
| `/猜塔卡牌帮助` | `/猜塔帮助` | 查看玩法和升级标记说明 |
| `/猜塔卡牌战绩` | `/猜塔战绩` | 查看个人战绩 |

以上指令也支持不带 `/` 的写法。已有对局时再次开局只会展示进度，不会更换答案。

## 提交猜测

```text
/我猜塔是 痛击
/我猜塔是 痛击+
```

支持规范卡名、正式英文名和已收录的名称写法；没有精确匹配时，也会尝试匹配相近名称。出现多个候选时，先用候选中的完整名称再猜一次。

- 无效、歧义和重复猜测不消耗机会；同一题换个名称仍算重复。
- **八项线索全部绿色就算获胜**，不要求卡名相同。因此另一张属性完全一致的卡也能猜中，终局仍会揭晓真正抽到的答案。
- 第 8 次猜中仍算获胜；用完机会后会自动揭晓答案。
- 终局会揭晓答案，并在有可用卡面时展示；进行中的猜测不会提前给出答案卡面。

### 基础与升级卡

| 标记 | 含义 |
| --- | --- |
| 不加 `+` | 猜基础版本 |
| 名称末尾加 `+` | 猜升级版本，例如 `痛击+` |
| 题目名称带 `(+)` | 基础与升级的八项线索一致，合并为同一道题 |

合并题用基础或升级名称都可以，不会占用两次不同猜测。`(+)` 是题目展示标记，不是选择升级版的指令；需要指定独立升级题时，请在名称末尾加 `+`。

## 怎么看线索

| 线索 | 比较内容 |
| --- | --- |
| 归属 | 所属角色或卡牌池 |
| 费用 | 能量、辉星等使用费用 |
| 类型 | 攻击、技能、能力等卡牌类型 |
| 稀有度 | 卡牌稀有度 |
| 自身词条 | 卡牌自身携带的关键词 |
| 状态词 | 卡牌涉及的状态词 |
| 版本 | 出现在一代、二代或两代 |
| 其他效果 | 其他效果标签 |

| 提示 | 含义 |
| --- | --- |
| 🟩／`✓` | 完全相同 |
| 🟨／`≈` | 部分内容重合，或费用接近 |
| 🟥／`×` | 不匹配 |

集合类线索两边都为空时也算相同。费用会综合比较能量与辉星，不使用高低箭头；「X」和「不能打出」也有各自的费用类别。

## 结束与战绩

群内任何成员都可以使用 `/结束猜塔` 揭晓答案。提交过有效猜测的玩家会计参与局数，**主动结束不计胜场**；没有有效猜测的空局不计战绩。

使用 `/猜塔战绩` 查看最终胜场、参与胜场、参与局数和活跃天数。由你完成获胜猜测才增加最终胜场；有效参与过、且最终获胜的对局会增加参与胜场。活跃天数按北京时间的结算日期计算，同一天只记一次。

只开局、查看进度、无效猜测或只点击结束，不算有效参与。
