# 数迹猜数字

## 概述

数迹（Numberle）是一个猜数字游戏。玩家需要根据每次猜测的颜色反馈，在规定次数内找出一个或多个数字答案。

绿色表示数字和位置都正确，黄色表示数字存在但位置错误，灰色表示该数字未匹配，或答案中该数字的可匹配数量已经用尽。重复数字会按照答案中的实际数量判定。

游戏支持1到35位数字和1到4个棋盘。多个棋盘共用每次猜测，每局的猜测次数为数字位数加棋盘数量。

## 指令

### 开始数迹

- 指令： `/数迹 [数字位数] [棋盘数量]`

- 别名： `/numberle`、`/猜数字`、`/数迹猜数字`

- 参数：

  - `数字位数`：范围为1到35，默认为5
  - `棋盘数量`：使用 `x1` 到 `x4`，默认为 `x1`

- 详情：

  开始一局数迹游戏。例如 `/数迹 8 x2` 会开始一局8位数字、两个棋盘的游戏

### 提示数迹

- 指令： `/提示数迹`

- 别名： `/提示numberle`

- 详情：

  查看各棋盘已经猜中数字和位置的线索，尚未确定的位置会显示为 `*`

### 结束数迹

- 指令： `/结束数迹`

- 详情：

  结束当前数迹游戏并查看全部答案

### 我猜数字是

- 指令： `/我猜数字是 [数字]`

- 别名： `/numberleguess`

- 参数：

  - `数字`：与本局位数相同的数字，允许包含前导零

- 详情：

  提交一次猜测，同时获取各棋盘的颜色反馈

### 使用数迹帮助

- 指令： `/使用数迹帮助`

- 详情：

  获取数迹游戏的帮助信息

## 我的战绩

- 指令：`/数迹战绩`

数字线索有没有越看越顺手？来看看自己一路攒下的战绩吧。

| 项目 | 计算方式 |
| --- | --- |
| 最终胜场 | 自己提交最后一次正确答案、让本局获胜的次数 |
| 参与胜场 | 本局提交过有效猜测，且大家最终猜中的次数，包含自己收尾的对局 |
| 参与局数 | 提交过有效猜测的对局数，同一局只记一次 |
| 活跃天数 | 有效参与过游戏的天数，按北京时间计算，每天只记一次 |

只是开局或查看帮助不会增加参与记录。支持按钮的平台还可以点击「我的战绩」，不用再翻指令。
