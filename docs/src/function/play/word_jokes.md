# 谐音梗大作战

## 概述

看看图，听听谐音——猜出被「谐」掉的原词吧！🐝

机器人会随机给出两张配图：

1. 一张对应 **谐音替换词**
2. 一张对应被遮住的 **原词**

并附上字数与分类提示（如「打一 4 字 成语」），由你猜出原词。

::: tip 玩法示意
题目类似：

> 这是 **蚝友**  
> 这是 `____`  
> 🔍 打一 4 字 成语

答案可能是「好久不见」。
:::

## 指令

### 谐音梗

- 指令： `/谐音梗`

- 别名： `玩玩谐音梗`、`谐音梗大作战`

- 详情：

  开始一轮谐音梗大作战。


### 我猜谐音梗是

- 指令： `/我猜谐音梗是 [原词]`

- 参数：

  - `原词`： 你认为的正确答案

- 详情：

  提交对本轮题目的猜测。猜对会揭晓答案并结束本轮；猜错可继续再猜，或使用「揭晓答案」放弃

- 使用示例：

  - `/我猜谐音梗是 好久不见`


### 揭晓谐音梗答案

- 指令： `/揭晓谐音梗答案`

- 详情：

  放弃作答，直接揭晓本轮正确答案并结束本轮
