# 以撒道具图鉴

## 概述

忘了某件《以撒的结合》道具有什么效果，或只记得一个外号？可以按名称、编号查询，也能按效果关键词搜索，再用品质、类型和道具池缩小范围。

详情会展示道具图片、名称、编号、品质、类型、基本效果和道具池；主动道具还会说明充能方式。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/以撒查道具 [名称或编号]` | 按名称、别名或编号查道具 |
| `/以撒搜道具 (关键词与筛选条件)` | 在名称和基本效果中搜索 |
| `/以撒随机道具 (关键词与筛选条件)` | 随机抽取一件符合条件的道具 |
| `/以撒菜单` | 查看用法和完整道具池名称 |

`/以撒道具` 是查道具的别名，`/以撒` 可以打开菜单。

## 按名称或编号查询

```text
/以撒查道具 硫磺火
/以撒道具 妈刀
/以撒查道具 C118
/以撒查道具 118
```

支持中文名、英文名和已收录的别名。编号可以写成 `C118`，也可以只写数字。重名时会列出带编号的候选，确认后再查询具体道具；名字没有精确命中时，也可能给出相近名称供参考。

## 搜索与筛选

多个关键词用空格分隔，结果需要**同时匹配**这些关键词。也可以不填关键词，只按筛选条件查看图鉴。

```text
/以撒搜道具 追踪
/以撒搜道具 追踪 天使房 品质4
/以撒搜道具 主动 商店
/以撒搜道具 品质4*2
```

| 筛选项 | 可用写法 |
| --- | --- |
| 品质 | `品质0`～`品质4` |
| 类型 | `主动`、`被动`、`跟班`；被动也包含被动跟班 |
| 道具池 | 如 `宝箱房`、`商店`、`恶魔房`、`天使房`；完整列表见 `/以撒菜单` |

每类筛选最多填写一个，普通搜索关键词最多 **5 个**。结果每页 **8 件**，在末尾加 `*页码` 翻页。

## 随机抽取

```text
/以撒随机道具
/以撒随机道具 品质4 天使房
/以撒随机道具 追踪
```

不填条件时从全图鉴抽取；填写条件时，只从严格符合关键词与筛选条件的道具中抽取，不用相近名称替代。

:::tip
这里是**候选图鉴内等概率随机**，不是模拟游戏内掉落，不考虑角色、解锁状态、道具池消耗或实际掉落权重。
:::

## 使用提示

- 名称查询不超过 32 个字符，搜索正文不超过 64 个字符。
- 分页只允许在末尾加一个 `*正整数`，页码最多 3 位；随机抽取不需要页码。
- 没有匹配结果时，可以减少关键词或筛选条件；效果说明供查阅，不代表已列出所有特殊联动。
