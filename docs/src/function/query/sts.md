# 杀戮尖塔查卡

## 概述

爬塔时忘了卡牌效果，或是只记得一个外号？来翻翻卡牌图鉴吧。

支持《杀戮尖塔》一代和二代，可以按名字查卡，也可以用效果关键词找卡。二代还可以查看社区对局统计和排行榜。

## 按名称查卡

- 指令：`/尖塔查卡 [卡名]`
- 别名：`/sts查卡`

中文名、英文名和已收录的俗称都可以试试；名字记得不太准时，也会尝试匹配相近的卡牌。如果找到多个结果，会先列出候选，再由你选择。

想只查某一代，可以换个指令前缀：

| 查询范围 | 查卡指令 | 其他可用前缀 |
| --- | --- | --- |
| 一代和二代 | `/尖塔查卡 [卡名]` | `sts` |
| 仅一代 | `/塔一查卡 [卡名]` | `塔1`、`sts1` |
| 仅二代 | `/塔二查卡 [卡名]` | `塔2`、`sts2` |

例如：

```text
/尖塔查卡 痛击
/塔一查卡 肚皮
/塔二查卡 雪碧
```

卡牌详情会显示卡面、类型、稀有度和所属角色；有升级版本的卡牌还可以对照升级后的效果。部分卡牌也会附上相关卡牌、事件关联或特殊来源，顺着提示就能继续查下去。

## 按关键词搜卡

- 指令：`/尖塔搜卡 [关键词]`
- 别名：`/sts搜卡`

在卡牌名称和效果描述中搜索。多个关键词用空格分隔，结果需要**同时包含**这些关键词。

```text
/尖塔搜卡 消耗 能量
```

结果较多时，在关键词后加上 `*页码` 翻页：

```text
/塔一搜卡 易伤*2
```

和查卡一样，搜卡也可以使用 `塔一`、`塔二` 等前缀限定代数。

## 二代统计与排行榜

二代卡牌详情中，有可用数据时会显示社区对局中的胜率、选取率等统计。基础卡与升级卡会分别统计，比较时记得看清版本哦。

| 指令 | 内容 |
| --- | --- |
| `/尖塔胜率排行 (页码)` | 按卡牌胜率查看排行 |
| `/尖塔选取率排行 (页码)` | 按卡牌选取率查看排行 |
| `/尖塔第一幕选取率排行 (页码)` | 查看第一幕选取率排行 |
| `/尖塔第二幕选取率排行 (页码)` | 查看第二幕选取率排行 |
| `/尖塔第三幕选取率排行 (页码)` | 查看第三幕选取率排行 |

不填页码时查看第一页；例如 `/尖塔胜率排行 2` 查看第二页。排行榜也可以用 `塔二` 前缀。

:::tip
这些是社区收录对局的统计，不是实时全服数据，也不代表一张卡适合所有牌组。数据仅供爬塔时参考，还是要看看自己手里缺什么~

目前一代不提供统计和排行榜。暂时取不到统计时，仍然可以查询卡牌本身。
:::

## 查看菜单

- 指令：`/尖塔菜单`
- 别名：`/尖塔`

查看查卡、搜索和排行入口。也可以用 `/塔一菜单` 或 `/塔二菜单` 只看对应游戏的菜单。
