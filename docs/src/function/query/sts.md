# 杀戮尖塔图鉴

## 概述

爬塔时忘了卡牌或遗物效果，或是只记得一个外号？来翻翻图鉴吧。

支持《杀戮尖塔》一代和二代的卡牌、遗物查询，可以按名字查找，也可以用效果关键词搜索。

## 按名称查卡

- 指令：`/尖塔查卡 [卡名]`
- 别名：`/sts查卡`

中文名、英文名和已收录的俗称都可以试试；名字记得不太准时，也会尝试匹配相近的卡牌。如果找到多个结果，会先列出候选，再由你选择。

想只查某一代，可以换个指令前缀：

| 查询范围 | 查卡指令 | 其他可用前缀 |
| --- | --- | --- |
| 一代和二代 | `/尖塔查卡 [卡名]` | `sts` |
| 仅一代 | `/塔一查卡 [卡名]` | `塔1`、`sts1` |
| 仅二代 | `/塔二查卡 [卡名]` | `塔2`、`sts2` |

例如：

```text
/尖塔查卡 痛击
/塔一查卡 肚皮
/塔二查卡 雪碧
```

卡牌详情会显示卡面、类型、稀有度和所属角色；有升级版本的卡牌还可以对照升级后的效果。部分卡牌也会附上相关卡牌、事件关联或特殊来源，顺着提示就能继续查下去。

## 按关键词搜卡

- 指令：`/尖塔搜卡 [关键词]`
- 别名：`/sts搜卡`

在卡牌名称和效果描述中搜索。多个关键词用空格分隔，结果需要**同时包含**这些关键词。

```text
/尖塔搜卡 消耗 能量
```

结果较多时，在关键词后加上 `*页码` 翻页：

```text
/塔一搜卡 易伤*2
```

和查卡一样，搜卡也可以使用 `塔一`、`塔二` 等前缀限定代数。

## 按名称查遗物

- 指令：`/尖塔查遗物 [名称]`
- 别名：`/sts查遗物`

支持中英文名称，名字记得不太准时也会尝试匹配。两代有同名遗物时，会先列出候选供你选择；也可以直接限定代数：

| 查询范围 | 指令 | 其他可用前缀 |
| --- | --- | --- |
| 一代和二代 | `/尖塔查遗物 [名称]` | `sts` |
| 仅一代 | `/塔一查遗物 [名称]` | `塔1`、`sts1` |
| 仅二代 | `/塔二查遗物 [名称]` | `塔2`、`sts2` |

```text
/尖塔查遗物 锚
/塔一查遗物 头环
/塔二查遗物 Anchor
```

遗物详情展示名称、稀有度、图标和效果。二代遗物在有可用统计时，还会显示持有率、胜率和评分；一代遗物不展示这些统计。

## 按关键词搜遗物

- 指令：`/尖塔搜遗物 [关键词]`
- 别名：`/sts搜遗物`

在名称和效果描述中搜索，多个关键词用空格分隔，需要同时匹配。也支持使用 `塔一`、`塔二` 等前缀限定代数，以及 `*页码` 翻页：

```text
/尖塔搜遗物 战斗 格挡
/塔二搜遗物 战斗*2
```

结果过多时，可以增加关键词缩小范围。结果列表中的查询指令使用遗物中文名，方便确认和复制；不支持按钮的平台也会显示对应的查询和翻页指令。

## 一代选取率与排行榜

一代卡牌详情在有可用统计时显示选取率，分别列出未升级和升级状态。

| 指令 | 内容 |
| --- | --- |
| `/塔一排行菜单` | 查看一代卡牌排行入口 |
| `/塔一选取率排行 (页码或卡名)` | 查看整体选取率排行 |
| `/塔一第一幕选取率排行 (页码或卡名)` | 查看第一幕选取率排行 |
| `/塔一第二幕选取率排行 (页码或卡名)` | 查看第二幕选取率排行 |
| `/塔一第三幕选取率排行 (页码或卡名)` | 查看第三幕选取率排行 |

不填参数时查看第一页，例如 `/塔一选取率排行 2` 查看第二页。也可以使用 `塔1`、`sts1` 前缀；排行中基础卡与升级卡分开列出，升级卡用 `+` 标记。

一代目前只提供选取率，不提供胜率详情或胜率排行。

## 二代统计与排行榜

二代卡牌详情中，有可用数据时会显示胜率、选取率等统计。基础卡与升级卡会分别统计，比较时记得看清版本哦。

| 指令 | 内容 |
| --- | --- |
| `/尖塔排行菜单` | 查看二代卡牌排行入口 |
| `/尖塔胜率排行 (页码或卡名)` | 按卡牌胜率查看排行 |
| `/尖塔选取率排行 (页码或卡名)` | 按卡牌选取率查看排行 |
| `/尖塔第一幕选取率排行 (页码或卡名)` | 查看第一幕选取率排行 |
| `/尖塔第二幕选取率排行 (页码或卡名)` | 查看第二幕选取率排行 |
| `/尖塔第三幕选取率排行 (页码或卡名)` | 查看第三幕选取率排行 |

不填参数时查看第一页；例如 `/尖塔胜率排行 2` 查看第二页。排行榜也可以用 `塔二` 前缀。

:::tip
`/尖塔排行菜单`、`/尖塔胜率排行`、`/尖塔选取率排行` 等指令查看的是**二代**卡牌；查看一代排行请使用 `塔一`、`塔1` 或 `sts1` 前缀。

暂时没有统计时，仍然可以查询卡牌和遗物本身。比例与评分只作参考，还是要看看自己的牌组缺什么~
:::

## 按卡名定位排行

上面的一代选取率排行，以及二代胜率、选取率和各幕选取率排行，都可以在命令后直接填写卡名，不必先知道页码：

```text
/塔一选取率排行 痛击
/尖塔胜率排行 痛击
/塔二第一幕选取率排行 痛击+
```

中文名、英文名和已收录的别名都可以使用，也会尝试匹配相近名称。

- 不加 `+` 时，列出匹配卡牌在当前榜单中的未升级与升级版本；卡名末尾加 `+` 时，只定位升级版。
- 查询会显示名次，并打开排名最靠前的匹配结果所在页。支持点击的平台可以从名次跳转到其他结果所在页；不支持点击的平台可以手动输入数字页码翻页。
- 只查找所选代数和当前榜单中有统计的卡牌；未上榜的卡牌不会显示名次。

仍然可以填写数字页码翻页，不填参数则查看第一页。

## 查看菜单

- 指令：`/尖塔菜单`
- 别名：`/尖塔`

查看卡牌、遗物查询与搜索入口。主菜单分别提供**塔一排行**和**塔二排行**入口，对应 `/塔一排行菜单`、`/塔二排行菜单`；`/尖塔排行菜单` 仍然查看二代排行。

也可以用 `/塔一菜单` 或 `/塔二菜单` 只看对应游戏的菜单，其中的排行入口会进入对应代数。
