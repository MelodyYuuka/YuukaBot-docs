# Minecraft 功能

## 概述

本功能提供了有关 Minecraft 的相关功能

:::tip
该功能已注册 **推送服务**

- mc更新检测
- je漏洞监测

详见 [服务管理](../admin/task_manager.md)
:::

## 指令

### mc状态

- 指令： `mc状态`

- 详情：

  查看 Minecraft 目前状态

### 上传皮肤

- 指令： `/上传皮肤`

- 详情：

  上传 Minecraft 皮肤到 Minecraft 皮肤服务器

### 生成网易MC随机名字

- 指令： `/生成wymc名字`

- 别名： `/随机wymc名字`

- 详情：

  网易MC名称生成器

### 搜索 MC 物品或方块

- 指令： `/搜mc物品 <物品名称>`

- 别名： `/搜我的世界物品`, `/搜我的世界方块`, `/搜MC方块`, `/搜MC物品`

- 参数：

  - `物品名称`：物品名称，支持模糊搜索

- 详情：

  搜索 Minecraft 物品或方块。支持使用中文名、英文名和资源 ID 模糊搜索，结果会显示图片以及不同版本使用的 ID

### 搜索 MC 实体

- 指令： `/搜MC实体 <实体名称>`

- 别名： `/搜MC生物`, `/搜我的世界实体`, `/搜我的世界生物`

- 参数：

  - `实体名称`：实体的中文名、英文名、旧称或资源 ID，支持模糊搜索

- 详情：

  搜索 Minecraft 实体信息。例如 `/搜MC实体 苦力怕` 或 `/搜MC生物 Zombie`。结果会显示实体图片、加入版本、不同版本使用的 ID 和旧称

### 综合搜索 MC ID

- 指令： `/搜mcid <关键词>`

- 参数：

  - `关键词`：物品、方块或实体的名称和资源 ID

- 详情：

  同时搜索物品、方块和实体。只确定名称但不知道类别时，可以优先使用这个指令

### MC活着吗

- 指令： `/mc活着吗`

- 别名： `/mc还活着吗`, `/mc死了吗`, `/mojang活着吗`, `/mojang还活着吗`, `/mojang死了吗`, `/mc存活状态`, `/mc存活检查`

- 详情：

  检查 Minecraft (Mojang) 服务器是否存活
