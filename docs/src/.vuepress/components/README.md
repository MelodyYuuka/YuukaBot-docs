# 聊天使用示例

`ChatExample` 是全站注册的静态 Vue 组件。设计参考 [NoneBot 快速上手](https://nonebot.dev/docs/quick-start) 中的聊天气泡，窗口只展示消息记录，不包含标题栏、输入框或发送按钮。

## 在功能页中使用

放在概述之后，保留原有指令、参数和玩法说明。演示性质写在文档正文里，不塞进聊天窗口：

```md
## 使用示例

下面展示菜单、同名卡牌选择、升级对照和事件关联查询的预设对话。

<ChatExample example="sts" />
```

当前示例为杀戮尖塔图鉴。全部对话在首次加载时展示，可滚动阅读；消息里的查询入口仅展示外观，不可点击。

## 新增示例

在同目录的 `chat-examples.ts` 中向 `chatExamples` 添加条目，再在功能页填写相同的 `example` 名称。

- `title`：功能名称，只用于窗口的无障碍名称，不显示标题栏。
- `steps`：预设对话列表；每项包含合法的 `command` 和 `replies`。
- 回复使用按消息片段顺序排列的 `content` 节点和静态键盘 `actions`。`content` 支持标题、引用、段落、列表、加粗、换行、内联指令和图片。
- 图片填写本地 `src`、明确的 `alt` 及机器人消息指定的 `width`、`height`；按原回复中的顺序和尺寸显示，窄屏仅缩小超出气泡的图片。
- `actions` 为按行分组的文字数组，只保存查询入口标签，不绑定事件或指令。
- 机器人消息统一使用 `/images/avatar/yuyuko.webp`，不使用站点 Logo。

## 内容约束

- 只渲染预设对话，不接收访客输入，不连接真实机器人或外部接口。
- 必须核对实际生产处理器的回复，保留原文、Markdown 格式、内联指令与键盘的区别、消息边界和图片顺序；不能把一条回复拆成多条，或自行添加标题、说明与按钮。
- 当前 STS 示例来自实际处理器的 Markdown 回复，并核对了本地统计缓存；示例中的卡牌没有可显示的统计，不编造胜率或选取率。
- 不为示例虚构歌曲 ID、统计数值、题库条目或实际运行截图。
- 回复通过 Vue 文本节点与固定白名单元素渲染，不使用 `v-html`；内联指令也只展示文字，不生成可点击链接。重要规则留在功能页正文，不混进聊天界面。
- 使用主题颜色，保持窄屏和深色模式可读；聊天记录支持键盘聚焦和滚动。
