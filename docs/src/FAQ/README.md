## ☯️QQ 第三方野生相关问题

### 在 QQ 下临时会话私聊 Bot 没有反应

由于在 QQ 平台下的 ***不可抗力*** 缘故，目前进行临时会话回复极易造成风控乃至封号，故暂不开放临时会话服务。

### 在 QQ 下 Bot 会突然消失一段时间

由于腾讯的一些 ***不可抗力*** ，Bot 可能经常被风控或封号，请不要担心。

> *幽幽子将如闪电般归来*

## ☯️QQ 官方Bot 相关问题

### QQ 官方bot 无响应？

默认情况下，需要先艾特幽幽子，她才能收到指令哦。QQ 群可以由群主按下面的流程开启免艾特；QQ 频道仍需先艾特。

### QQ 群怎么开启免艾特／全量消息？

请由**群主**在手机 QQ 中操作。图示要求 **QQ 9.2.90 及以上版本**，建议先更新到最新版。下面的流程适用于 **QQ 官方平台的群聊**，不适用于 QQ 频道；不同系统、客户端版本的入口可能不同，以实际显示为准。

#### 方法一：从幽幽子主页开启

1. 在需要开启的群里，点击**幽幽子的头像**，进入主页。
2. 点击主页右上角的**设置按钮（齿轮图标）**。
3. 设置下面两项权限：
   - **机器人可获取的群聊消息范围**：选择「获取群内全部消息」。这就是**全量消息**权限，让幽幽子能够收到没有艾特她的群消息。
   - **机器人主动在群聊内发言**：打开开关，允许幽幽子主动发送消息，例如定时任务推送。
4. 按页面提示完成授权。群里出现「群主已授权幽幽子查看群内全部对话……」的提示，就说明全量消息授权成功啦。

![从群内头像进入幽幽子主页，点击右上角设置，开启全量消息和主动发言权限，再查看群内授权成功提示](/images/qq-atless-guide.webp)

也可以先艾特幽幽子，发送 `/免艾特申请`，在群里查看这张操作图。

#### 方法二：通过指令进入授权页

如果找不到上面的设置入口，或按图操作没有成功，可以尝试备用方案：

也可以打开[幽幽子免艾特备用入口](https://link.yunmengdu.cn/yuyuko)，按页面提示操作。

1. 在当前群里，先**艾特幽幽子**，发送 `/免艾特申请 群号`，将 `群号` 换成当前群的纯数字群号。也可以使用别名 `/全量申请 群号`。
2. 由群主点击回复中的「点这里就可以免艾特啦🐝」按钮，进入「获取群聊相关权限」页面。
3. 按下图，将消息范围设为 **「获取群内全部消息」**，并开启 **「机器人主动在群聊内发言」**。
4. 点击底部的 **「同意授权」**。只修改选项、不确认授权，还没有完成哦。

![QQ 群权限开启示意：选择获取群内全部消息，开启主动发言，然后点击同意授权](/images/qq-full-message-permissions.webp)

完成任一方法后，返回群聊，不艾特幽幽子，直接发送 `/帮助`，检查是否能够正常回应。

如果没有看到入口、按钮打不开，或授权后仍无响应：

- 确认操作账号是**群主**，两项权限已开启；使用备用方案时，还需核对群号，并点击「同意授权」。
- 更新手机 QQ 后再试；不同系统、客户端版本的入口可能不同，以实际显示为准。
- 暂时无法开启时，仍可以先艾特幽幽子再发送指令。

## 🐝跨平台问题

### 我在 `QQGuild` 和 `QQ` 上的数据不一样？

由于腾讯的限制，Bot 无法在`频道/官方群接口`上获取用户真实 QQ，数据无法自适应同步，请使用 [跨平台服务](../function/admin/platform.md) 手动绑定同步
